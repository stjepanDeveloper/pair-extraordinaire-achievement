## Contribution Guidelines

Please follow the below steps to contribute to this project:

1. After some new Github changes the process is a bit different, so I need to invite you as a collaborator.
2. After you accept to collaboration request fork the repository and make some changes to the Contributors.md (add your email like in the example above).
2. Use Github Desktop to create a pull request with the said changes.
3. IMPORTANT - Include your GitHub primary email or no-reply email if privacy is a concern.
4. Push the changes to the Github.
5. After that I will add a descriptive commit message along with a co-author tag and merge the branch.
6. Check your Github profile, your achievement should be visible!

Thank you for contributing to this project! Cheers
